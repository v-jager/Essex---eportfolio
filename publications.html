Improving the value of population health data for health policy and decision-making using machine learning algorithms in EQ-5D-5L index estimation

This study investigates the application of machine learning techniques to estimate EQ-5D-5L health utility scores using routinely collected population-level data. A large dataset (N=9,324) was analysed, and fourteen machine learning models—including AdaBoost, Multilayer Perceptron (MLP), XGBoost, and deep neural networks—were systematically compared across multiple scenarios. The results showed that ensemble methods, particularly AdaBoost, achieved the best overall performance, demonstrating the ability of ML models to capture complex, non-linear relationships in health data.

Publication: Population norms for the EQ-5D-5L for Hungary

This publication develops Hungarian EQ-5D-5L population norms by comparing results from online surveys and computer-assisted personal interviews (CAPI). From a machine learning perspective, the study is especially relevant because it used both traditional linear regression and random forest regression to investigate the determinants of EQ-5D-5L index values. Although the selected explanatory variables — survey mode, education, sex, and age — explained only around 7–10% of the variance, the random forest model provided an important robustness check against the traditional regression approach. The analysis highlighted that age had the largest effect on EQ-5D-5L values, while sex had the smallest effect, and demonstrated how ML methods can complement classical statistical modelling in population health research.
