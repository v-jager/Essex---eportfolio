Unit 11 Reflection: Model Performance Evaluation

This unit focused on evaluating machine learning models using different performance metrics, including accuracy, F1 score, R², and the Area Under the Curve (AUC). The notebook demonstrates that different metrics capture different aspects of model performance, depending on whether the task is classification or regression.

A key takeaway is that relying on a single metric can be misleading. For example, accuracy may appear high even when a model performs poorly on minority classes, while metrics such as AUC provide a more robust measure of a model’s ability to distinguish between classes. Similarly, R² is useful in regression tasks to measure how well the model explains variance in the data.

The experiments also showed that model performance is sensitive to parameter choices. For instance, in the case of the support vector classifier, the polynomial kernel consistently achieved higher AUC values than the linear kernel, indicating better classification performance under the tested conditions.
