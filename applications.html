Note: The following projects illustrate real-world applications of machine learning methods in official statistics and research environments.

Nowcasting with Machine Learning

This project focused on nowcasting key economic indicators, including production and tourism metrics, using advanced machine learning techniques. Multiple modelling approaches were explored, including classical algorithms enhanced with Particle Swarm Optimization (PSO) for hyperparameter tuning, as well as deep learning architectures such as LSTM-based neural networks. These models were designed to capture temporal dependencies in time series data, using rolling window inputs and feature scaling. The project also incorporated ensemble methods and Gaussian process regression for probabilistic benchmarking. This work demonstrates how machine learning can be effectively applied to real-time statistical estimation under conditions of limited and partially available data.

Machine Learning for Border Crossing Traffic (CorrForest)

In this project, machine learning techniques were applied to model and impute missing data in border crossing traffic statistics derived from road camera systems. The approach combined correlation analysis with a random forest–based method, resulting in the development of a custom algorithm called CorrForest. This method leverages the strong relationships between traffic patterns and related economic indicators, such as industrial production, while also exploiting the network structure of observation points. The model proved effective in reconstructing missing values and capturing underlying temporal patterns, illustrating the practical value of ensemble learning methods in official statistics.

Text Classification with Transformers and LLMs

This project addressed the classification of online job advertisements into ISCO occupational categories using modern natural language processing techniques. Starting from traditional approaches such as TF-IDF vectorisation and classical classifiers, the work evolved towards the use of transformer-based models, including fine-tuned DistilBERT architectures. Due to the lack of labelled training data, synthetic datasets were generated using large language models, enabling supervised learning in a low-resource setting. The final solution combined pretrained embeddings with neural classification layers, achieving significant improvements over baseline methods. This project highlights the integration of LLMs, deep learning, and practical constraints such as limited data availability and computational resources.
